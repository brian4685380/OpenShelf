# OpenShelf v0.10.0

## More reliable floating-shelf recovery

- Prevent a stale mouse-down from leaving the shelf stuck waiting for a drag that already ended, blocking recovery after switching apps or fullscreen Spaces.
- Use live macOS mouse-button state for shelf recovery and preparation of the next shelf. Recovery still waits while you are actually dragging, preserving native drops.
- Add opt-in fullscreen diagnostics for troubleshooting visibility and recovery state. Diagnostics are off by default and exclude shelf filenames and other apps' window contents.

This release also includes v0.9.0's remote file imports: `shelf myserver:/path/to/file` downloads a temporary local copy into the active shelf using your SSH configuration. Remote originals stay untouched.

Validated with 128 passing tests (one optional screenshot test skipped), a regression that failed against the previous mouse-state guard, a live fullscreen test app, and user acceptance of the running build.

## Install or update

Save temporary clips/downloads and quit OpenShelf first. Shelf contents are session-only.

```sh
brew update
brew upgrade --cask brian4685380/openshelf/openshelf
open /Applications/OpenShelf.app
shelf --version
```

For a first install, use `brew install --cask brian4685380/openshelf/openshelf`, or download the DMG and drag **OpenShelf → Applications**. Homebrew also installs the bundled `shelf` command. Restart the app after upgrading so the app and CLI versions match.

Requires macOS 13+ and Apple Silicon for the downloadable app. Intel users can build from source. Releases are ad-hoc signed, **not Apple-notarized**; see the [installation guide](https://github.com/brian4685380/OpenShelf#install). ZIP and DMG checksums are included in `SHA256SUMS`.
