# OpenShelf v0.7.0

A more comfortable shelf, whether you work with the mouse, keyboard, or Terminal.

## Highlights

- **Pin it open.** The new pin control (⌘P) keeps the shelf expanded, even when empty.
- **Keyboard workflow.** Navigate with arrows, extend/shrink a selection with Shift, select all, copy files or paths, preview with Space, open with Return, and remove entries with Delete. Escape clears selection, then closes the shelf.
- **Clearer UI.** Selected/total counts, full-path tooltips, accessible row actions, a clipboard button in the empty shelf, and menu-bar shortcut help.
- **A CLI you can check.** `shelf --help`, `--version`, literal dash-prefixed filenames, complete input validation, and confirmation from the running app. The app still launches automatically when needed.
- **Recover missed CLI notifications.** A private request/reply queue and periodic checks make delivery independent of wake-up notifications.
- **Window and drag fixes.** More resilient floating behavior across Desktops, fullscreen and display changes. Drag rows out through any side—even after starting a vertical reorder.
- **Consistent additions.** New clipboard/CLI items clear selection and show the same feedback as drops.
- **Safer temporary exports.** Copied or dragged-out text/images stay available until quit, even after their shelf entries disappear.
- **Responsive file monitoring.** Watcher setup no longer blocks the main UI thread when macOS takes time to open a file descriptor.

The repository now includes light/dark UI screenshots, contribution and release guides, issue templates, and macOS CI.

## Install or update

```sh
brew tap brian4685380/openshelf
brew install --cask openshelf
```

Already installed? Quit OpenShelf, then run `brew update && brew upgrade --cask openshelf` and reopen the app. Shelf contents are session-only, so save temporary items you want to keep before quitting.

Or download the DMG below and drag OpenShelf into Applications. The ZIP includes both the app and its bundled `shelf` CLI. `SHA256SUMS` contains checksums for both downloads.

**Requirements:** macOS 13+, Apple Silicon. Releases remain ad-hoc signed, **not Apple-notarized**. See the README for first-launch guidance. No accounts or app-managed uploads.
