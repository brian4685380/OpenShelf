# OpenShelf v0.8.0

## Multiple shelves, separate workflows

Keep several floating shelves open at once, each with its own files, order, selection, and pin state.

- Start a shelf with the header **+**, **⌘N**, **New Shelf** in the menu bar, or a new drag to either screen edge—even when that edge already has a shelf.
- Drop directly onto an existing shelf to add to it. Re-entering the edge during the same drag reuses its preview instead of creating duplicates.
- Shelves use the plain **OpenShelf** title. The **Shelves** menu shows a first-filename preview and marks the active shelf, so no numbered titles are needed.
- Drag individual files or selected groups between shelves. Temporary text and image clips receive independent copies, so clearing the source cannot break the destination.
- Hide a shelf with **×** and reopen it from the menu without losing its contents. Use **Remove Active Shelf…** to remove it explicitly.
- The `shelf` CLI sends files to the last shelf you interacted with; clipboard paste goes to the focused shelf.

## Reliability

- Adding files to a manually positioned shelf no longer snaps it back to the screen edge.
- Full-panel drop destinations follow their own shelf when it moves.
- New edge destinations are prepared while idle; canceled empty previews are hidden for reuse.
- Existing Finder drops, multi-selection, reordering, auto-scroll, pinning, keyboard shortcuts, and CLI delivery retain regression coverage.

## Install or update

Save temporary clips and quit OpenShelf before updating: all shelf contents remain **session-only**.

```sh
brew update
brew upgrade --cask brian4685380/openshelf/openshelf
open /Applications/OpenShelf.app
```

For a first install, use `brew install --cask brian4685380/openshelf/openshelf`, or download the DMG below and drag **OpenShelf → Applications**. Homebrew also links the bundled `shelf` command.

Requires macOS 13+ and Apple Silicon for the downloadable app. Intel users can build from source. Releases are ad-hoc signed, **not Apple-notarized**; see the [installation guide](https://github.com/brian4685380/OpenShelf#install) for macOS first-launch guidance.

ZIP and DMG checksums are included in `SHA256SUMS`.
