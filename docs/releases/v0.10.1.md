# OpenShelf v0.10.1

## Shelf stays above other apps' floating windows

- Other applications can raise their own always-on-top windows (picture in picture, call controls, screenshot tools, other utilities) without activating or receiving a click. The shelf previously stayed underneath until your next click. It now returns to the top within about a third of a second.
- Recovery still waits while you are dragging, preserving native Finder drops. Windows that macOS places above the floating level, such as some system overlays, are left alone.

Validated with 131 passing tests (one optional screenshot test skipped) and a live two-process check in which another app's floating window covered the shelf and a reorder restored it.

## Install or update

Save temporary clips/downloads and quit OpenShelf first. Shelf contents are session-only.

```sh
brew update
brew upgrade --cask brian4685380/openshelf/openshelf
open /Applications/OpenShelf.app
shelf --version
```

For a first install, use `brew install --cask brian4685380/openshelf/openshelf`, or download the DMG and drag **OpenShelf → Applications**. Homebrew also installs the bundled `shelf` command. Restart the app after upgrading so the app and CLI versions match.

Requires macOS 13+ and Apple Silicon for the downloadable app. Intel users can build from source. Releases are ad-hoc signed, **not Apple-notarized**; see the [installation guide](https://github.com/brian4685380/OpenShelf#install). ZIP and DMG checksums are included in `SHA256SUMS`.
