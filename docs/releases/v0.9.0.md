# OpenShelf v0.9.0

## Remote files, straight to your shelf

The `shelf` command now accepts SCP-style remote sources, using your existing SSH configuration, aliases, keys, and terminal authentication prompts:

```sh
shelf myserver:/home/me/report.pdf
shelf user@myserver:projects/photos
shelf "myserver:projects/Design notes.txt" ./local-file.txt
```

- Downloads files and directories into private temporary storage, then adds them to the active shelf. OpenShelf launches and opens a shelf if needed.
- Mix local and remote inputs in one command. All transfers finish before any entries are added; failed or interrupted transfers clean up their partial downloads.
- Remote originals are never moved, deleted, or synchronized back, including when you drag a downloaded item out of the shelf.
- Downloaded copies are session-only. Removing an unexported entry can delete its local copy; successfully dragged/copied-out sources remain readable until quit. Save anything you want to keep.
- Copying a downloaded item between shelves creates an independent temporary copy. Different remote sources with the same filename cannot overwrite each other.
- If the app cannot confirm ownership, the CLI retains downloaded copies and prints their paths for recovery.

Configure ports and jump hosts in `~/.ssh/config`. Quote sources with spaces, and use `./name:with-colon` for local filenames containing a colon. Directory downloads are recursive and follow symlinks according to system `scp` behavior. Host-key verification remains enabled; OpenShelf does not store SSH passwords.

Validated with 127 passing tests (one optional screenshot test skipped), including real local SCP/SFTP fixture transfers, temporary-file lifecycle checks, active-shelf routing, and cancellation cleanup. Authentication against a user's SSH server remains a manual check.

## Install or update

Save temporary clips/downloads and quit OpenShelf first. Shelves are session-only. **Both the CLI and running app must be v0.9.0 or newer for remote imports.**

```sh
brew update
brew upgrade --cask brian4685380/openshelf/openshelf
open /Applications/OpenShelf.app
shelf --version
```

For a first install, use `brew install --cask brian4685380/openshelf/openshelf`, or download the DMG and drag **OpenShelf → Applications**. Homebrew also installs the bundled `shelf` command; DMG users can choose **Install CLI Tool…** from OpenShelf's menu.

Requires macOS 13+ and Apple Silicon for the downloadable app. Intel users can build from source. Releases are ad-hoc signed, **not Apple-notarized**; see the [installation guide](https://github.com/brian4685380/OpenShelf#install). ZIP and DMG checksums are included in `SHA256SUMS`.
