# OpenShelf v0.8.1

## Reliable floating shelves across Desktops

- Recover a shelf left attached to a previous Desktop/fullscreen Space instead of only bringing the existing window forward.
- Repair the shelf's full-content drop destination independently, so the visible window and its accepting area recover together.
- Keep the active shelf above other shelves and their invisible drop destinations after recovery.
- Preserve drag safety: recovery waits until a file drag ends, keeps the interactive floating window level, and does not repeatedly reorder healthy shelves.

Validated with 117 passing tests (one optional screenshot test skipped), a release build, and user acceptance of the Desktop-switch fix.

## Install or update

Save temporary clipboard items and quit OpenShelf first. Shelves are session-only.

```sh
brew update
brew upgrade --cask brian4685380/openshelf/openshelf
open /Applications/OpenShelf.app
```

For a first install, use `brew install --cask brian4685380/openshelf/openshelf`, or download the DMG and drag **OpenShelf → Applications**. Homebrew also installs the bundled `shelf` command.

Requires macOS 13+ and Apple Silicon for the downloadable app. Intel users can build from source. Releases are ad-hoc signed, **not Apple-notarized**; see the [installation guide](https://github.com/brian4685380/OpenShelf#install). ZIP and DMG checksums are included in `SHA256SUMS`.
